A folder listing now marks each folder that has no file anywhere below it, and the drive's new View options menu has a "Hide empty folders" checkbox that this browser remembers. The flat all-files view is now "Files with folders as tags": every folder on a file's path shows as a tag beside its labels, and a tag bar above the list filters to the files that carry all the tags you pick.
