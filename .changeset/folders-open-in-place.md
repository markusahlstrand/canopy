Folders open in place in the list view: the arrow beside a folder (or Right/Left on the keyboard) shows its contents indented under it, a level at a time, without leaving the folder on screen. Rows inside an open folder can be previewed, selected, moved, trashed and dropped onto like any other, and double-clicking a nested folder enters it with the folders in between in the breadcrumbs. Offline, an opened folder reads from the metadata mirror.
