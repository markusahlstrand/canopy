Files and folders have a "Label with AI" menu item in spaces where Document AI is on. On a file it labels and describes the file right away, without waiting out the daily cooldown. On a folder it labels the files under it that have no labels yet, up to 200 at a time; "Re-label all with AI" labels all of them again. Document AI now also tells the model which folder a file is filed in, so a folder like "Client invoices" helps it pick the right label and category.
