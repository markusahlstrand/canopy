The drive's folder header looks like the old portal again. The strip of full-width buttons under the top bar ("Share this folder", "Copy folder link", "Available offline on this device") is gone; each folder gets a page header instead — its name and item count on the left, and compact icon buttons on the right (Share, Copy link, Make available offline / Available offline) beside search and the list/grid toggle. The copied link and the offline "updated" time move into tooltips (still announced to screen readers), progress and errors show as one small line under the header only while they apply, and the content area gets the portal's roomier desktop padding.
