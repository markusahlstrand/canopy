# ownCloud

> The original self-hosted file platform; its Infinite Scale rewrite goes cloud-native.

## What it is

A self-hosted file sync & share platform. Classic ownCloud (PHP) pioneered the category and has a
broad app / extension model; **Infinite Scale (oCIS)** is a ground-up Go rewrite built for
scalability around a microservice and "spaces" model. Desktop + mobile sync clients; document
editing via Collabora / OnlyOffice.

## Where it beats Canopy

- Mature, with years of production use and an app ecosystem (classic).
- oCIS scales horizontally; first-class sync clients and co-editing.
- Enterprise features, admin tooling, federation.

## Where Canopy differs

- **Footprint** — a single Worker / Node process vs an oCIS microservice stack or a PHP + database
  server.
- Bring-your-own object storage and edge-serverless deployment.
- A slim core with sandboxed plugins; Canopy is far younger and smaller.

## Pick ownCloud if

You want a mature, self-hosted sync-and-share platform — classic for the app ecosystem, Infinite
Scale for a modern, scalable core.
