# Syncthing

> Open-source, peer-to-peer continuous file sync — no server, no cloud.

## What it is

Syncthing keeps folders in sync directly between your devices over an encrypted peer-to-peer
connection. There's no central server and no web "drive" — it's a sync **engine**, with a local
web UI for configuration.

## Where it beats Canopy

- Serverless **sync** in the truest sense: device-to-device, no cloud, encrypted in transit.
- Excellent for keeping folders mirrored across your own machines.

## Where Canopy differs

- A different model. Canopy is a centralised drive / portal (a shared web UI, a sharing graph,
  plugins), not peer sync, and it has no desktop sync client.
- You could even point Canopy at a folder that Syncthing keeps in sync.

## Pick Syncthing if

You want to mirror folders directly between your own devices, with no server in the middle.
