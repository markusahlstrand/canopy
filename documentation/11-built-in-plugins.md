# Built-in features

The current drive vertical includes its drive UI, a command palette, and built-in previews for text, images, and PDF. It also supports search by name, current extracted text, description, and labels. A durable backfill revisits older files and failed extractions.

The old portal had Calendar, Tasks, Document AI, a plugin store, and sandboxed viewers. That portal was retired. The drive vertical now has its own plugin catalog, Studio, scoped installs, and sandboxed runtime viewers and full-view apps. This does not mean every old portal plugin has been ported. The repository examples are available as bundled catalog entries or migration inputs.

Search is a built-in drive feature. The command palette gives quick keyboard access; the results view gives room for result details and filters. These entry points are always present regardless of installed plugins.

See [How plugins work](03-how-plugins-work.md) for the current runtime and trust boundary. [#295](https://github.com/markusahlstrand/canopy/issues/295) tracks deployed acceptance.
