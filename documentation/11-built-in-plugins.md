# Built-in features

The current drive vertical includes its drive UI, a command palette, and built-in previews for text, images, and PDF. It also supports file search by name and extracted PDF text, although text backfill for older files remains [open](https://github.com/markusahlstrand/canopy/issues/66).

The old portal had Calendar, Tasks, Document AI, a plugin store, and sandboxed viewers. That portal was retired. The current vertical does not install or run those plugins. Their packages and examples remain in this repository as migration inputs.

The future viewer and plugin boundary is tracked in [#73](https://github.com/markusahlstrand/canopy/issues/73). See [How plugins work](03-how-plugins-work.md) for its current status.
