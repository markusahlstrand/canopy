# Proton Drive

> A privacy-first cloud drive with end-to-end encryption.

## What it is

A hosted consumer drive from the Proton suite, with **end-to-end encryption** of files and
metadata, mobile / desktop apps, and sharing. Your files live on Proton's servers but are
encrypted so Proton can't read them.

## Where it beats Canopy

- True **end-to-end encryption** — Canopy does not encrypt file *contents* E2E.
- Polished apps, zero ops, and a trusted privacy brand.

## Where Canopy differs

- Self-hosted / edge-native with storage **you** own and run; open source.
- An extensible plugin platform and bring-your-own identity. Document AI is the opposite trade-off
  from E2E — it requires the server to *read* content to label it.
- Canopy encrypts *secrets* (tokens, AI keys) at rest, not file bodies.

## Pick Proton Drive if

End-to-end encryption and a privacy-first hosted experience are your priority.
