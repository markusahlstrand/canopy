# Dropbox

> The benchmark for file sync — a superb desktop client and block-level delta sync.

## What it is

A hosted sync-and-share service known for the most reliable desktop sync in the category
(block-level / delta transfer, LAN sync, online-only files), plus Paper, sharing, and solid mobile
apps. Your files live on Dropbox's servers.

## Where it beats Canopy

- Best-in-class **sync**: block-level delta uploads, selective / online-only files, conflict handling.
- Mature desktop clients (Windows / macOS / Linux) and mobile apps; offline-first.
- Reliability, polish, and a large sharing / collaboration feature set.

## Where Canopy differs

- Canopy has **no desktop sync client** — it offers a WebDAV mount and a web UI, not Dropbox-style
  continuous sync.
- Your bytes stay in storage you own; Canopy is self-hosted / edge-native and open source.
- Extensible via sandboxed plugins; bring-your-own identity (OIDC).

## Pick Dropbox if

Rock-solid file sync across devices is the priority and a hosted service is fine.
