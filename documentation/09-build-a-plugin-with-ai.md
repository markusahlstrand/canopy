# Build a plugin with AI

The old Plugin Studio ran inside the retired portal. The current Substrat drive vertical has no runtime plugin installation or AI authoring flow.

The viewer and authoring model is being decided in [#73: Web components and the hosted vertical](https://github.com/markusahlstrand/canopy/issues/73). Until it lands, an AI-generated legacy <code>canopy.json</code> viewer will not appear in the current drive. See [Writing a plugin](05-writing-a-plugin.md) for the status of the older examples.
