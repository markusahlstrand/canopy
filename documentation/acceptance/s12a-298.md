# S12a #298: Offline folders and files

Parent: [#78](https://github.com/markusahlstrand/canopy/issues/78). Also tracks #302, the folder-control and recursive-sync slice.

## Correction

Every offline-content transaction observes its completion rejection immediately. Quota failures during pin creation, status updates, and retained-version renames no longer produce an additional unhandled rejection. Failed writes leave the previously saved version intact.

## Local evidence

Baseline: `e192c2c` (8 October 2026). The focused app suite passed 18 tests. Run from `apps/drive-vertical`:

```sh
pnpm exec vitest run --project app offline-transaction-failures offline-content offline-folder-sync offline-quota
pnpm exec tsc -p tsconfig.app.json --noEmit
```

With all seven S12a correction branches combined, 534 app tests in 91 files and 688 scope-drive tests in 12 files passed. The app TypeScript check and production Vite build also passed.

The app tests use React/jsdom and synthetic API fixtures. Offline tests use fake-indexeddb; they do not establish native-browser quota behavior. Scope-drive tests exercise the real SQLite scope host, including permissions, search, and sharing.
