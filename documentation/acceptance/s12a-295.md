# S12a #295: Plugin install and runtime

Parent: [#78](https://github.com/markusahlstrand/canopy/issues/78).
## Correction

Failed plugin sandboxes have an explicit retry that creates a fresh frame. Edits made during an in-flight plugin save remain marked as unsaved after that save completes.

## Local evidence

Baseline: `e192c2c` (8 October 2026). The focused app suite passed 33 tests. Run from `apps/drive-vertical`:

```sh
pnpm exec vitest run --project app sandbox-plugin sandbox-security plugin-management
pnpm exec tsc -p tsconfig.app.json --noEmit
```

With all seven S12a correction branches combined, 534 app tests in 91 files and 688 scope-drive tests in 12 files passed. The app TypeScript check and production Vite build also passed.

The app tests use React/jsdom and synthetic API fixtures. Offline tests use fake-indexeddb; they do not establish native-browser quota behavior. Scope-drive tests exercise the real SQLite scope host, including permissions, search, and sharing.
