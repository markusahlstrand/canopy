# S12a #295: Plugin install and runtime

Parent: [#78](https://github.com/markusahlstrand/canopy/issues/78).

## Behavior and corrections

A failed sandbox can retry in a fresh frame. Native iframe interaction is blocked while a save is pending; a successful save produces a new file version, which remounts the editor on the accepted bytes. Reviewing the same catalog artifact again resets capability approval; source, manifest and audience edits reset it immediately. A signed GitHub import keeps its server-attested provenance even when its bytes match a bundled catalog entry.

## Real-browser evidence

On 9 October 2026, `e2e/plugins.spec.ts` passed eight cases across isolated Chromium desktop and mobile projects. The built SPA, real Worker, OIDC login, real stores and plugin bridge handle accepted operations. The public GitHub import fetches the real repository at pinned ref `e192c2c`; an ephemeral local router secret enables real signed import tokens. Only the explicit byte-failure and delayed-save cases intercept transport. No production account or browser profile is used.

| Acceptance | Evidence |
| --- | --- |
| Personal and space catalog installs | Separate approval, scope filters, enable/disable and retained independent installs |
| ZIP import | Synthetic app/editor archives install, run in native sandbox frames, and malformed ZIPs show errors with installation disabled |
| GitHub import | Actual public Image Viewer import installs with GitHub provenance retained |
| npm error path | Actual public React package has no Canopy manifest; review explains the failure and prevents installation |
| Apps and viewers | Disabled app disappears from rail/palette; enabled app launches; installed editor appears in the preview picker |
| Edit versus build | Editing retains one install and changes its runtime; building another ID preserves the old app |
| Runtime retry and pending save | Failed immutable bytes recover; the iframe root is inert and cannot focus its editor during a real pending save, then reloads accepted bytes |

The full app suite passed 527 tests in 88 files. Worker, app and browser-suite TypeScript checks passed. Source/capability approval and matching-catalog GitHub provenance have component regressions.
