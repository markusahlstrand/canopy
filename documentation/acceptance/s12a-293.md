## Correction

Invitation, removal, and withdrawal responses are ignored after their dialog visit ends. New visits reset busy state and cannot display an invitation link or error from the old visit.

## Complete shell browser coverage

On 8 October 2026, all 10 browser cases and all 524 UI tests passed; worker/app and browser-test TypeScript checks passed. The PR includes six desktop/mobile Chromium acceptance cases for the shell, in addition to the four inherited drive cases. The built SPA uses real OIDC, SQLite Durable Objects, and R2. Only the external control plane is replaced by a local fixture: it consumes the real durable space-creation intent and calls the platform's normal configure/provision/settle routes.
