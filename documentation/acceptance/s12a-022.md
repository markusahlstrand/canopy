# S12a #22: Search UI contract and entry points

Parent: [#78](https://github.com/markusahlstrand/canopy/issues/78).

- **Decision:** search is built into the drive, not an installed plugin. The ⌘K / Ctrl-K palette is the quick keyboard entry point; the results view shows the full result set. Disabling plugins removes neither.
- **Documentation:** the built-in exception is stated in the core-vs-plugin guide (#335).
- **Verification:** both entry points are covered by the real-browser suite in [s12a-292.md](s12a-292.md).

The hosted-verification step is waived by the owner (19 October 2026): Canopy is not yet a production app.
