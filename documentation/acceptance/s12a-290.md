# S12a #290: Browsing and file actions

Parent: [#78](https://github.com/markusahlstrand/canopy/issues/78).
## Implementation and browser evidence

The PR now exercises the complete supported drive workflow rather than only a name-dialog correction. Create/rename retains the proposed name on failure and blocks duplicate writes. Live and manual refreshes retain every file/folder page already loaded, re-reading their current authorized rows rather than collapsing back to page one. The row Download action now uses the browser download mechanism with the file name, instead of opening inline text in a new tab.

On 8 October 2026, `pnpm test:e2e` passed all six cases in desktop Chromium (1280×720) and mobile Chromium (Pixel 7, 393×727):

| Checklist | Browser result |
|---|---|
| Root/nested labels, empty states, breadcrumbs, mobile parent navigation | Pass; current space and nested folder names are shown; no horizontal overflow |
| Paged folder browsing | Pass; create 21 folders, retain the next listing page across Refresh, open its final folder, and download its complete bytes |
| Upload/download | Pass; saved file name and complete bytes match the synthetic upload |
| File and folder rename/move | Pass; the destination lists the same renamed items and the source no longer does |
| Trash/restore | Pass for files; restored download retains the current bytes |
| Versions | Pass; re-upload preserves two versions and both historical downloads return their original bytes |
| Collision and failure recovery | Pass; a real name collision and one injected transport failure preserve the proposed name; retry writes it successfully |

The suite runs the built SPA, real worker, real OIDC authorization-code login, SQLite Durable Objects, and R2 attachment storage. It creates an empty disposable install for every run. Only the transport-failure case intercepts a request; accepted writes and all other reads go to the worker. CI runs the suite independently of the component tests.

```sh
pnpm exec playwright install chromium
pnpm typecheck:e2e
pnpm test:e2e
pnpm --filter @canopy/drive-vertical typecheck
pnpm --filter @canopy/drive-vertical exec vitest run --project app name-dialog drive.dom
```

Folders offer Open, Share, Rename, and Move. Folder download, Trash, and version history are absent from the model and UI; file-only actions are not presented on folders. Sharing is accepted separately in #294. The local browser run does not establish hosted OIDC, routing, or deployment behavior.
