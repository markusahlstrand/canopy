# S12a #294: Folder sharing

Parent: [#78](https://github.com/markusahlstrand/canopy/issues/78).
## Correction

Adding access waits for both the roster and the existing grants. Failed access lookup cannot expose everyone as a new share target or accidentally downgrade an existing grant. Existing grant removal remains available when only the roster fails.
