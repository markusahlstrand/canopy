# Seafile

> Self-hosted file sync with a library model and block-level storage — a self-hosted Dropbox.

## What it is

A self-hosted sync-and-share server organized around "libraries," with block-level deduplicated
storage and fast, reliable sync clients. Optional client-side-encrypted libraries; a focused
feature set rather than a broad app platform.

## Where it beats Canopy

- Excellent, fast **sync** with block-level dedup and solid desktop / mobile clients.
- Optional client-side encrypted libraries.
- Proven performance for large file sets.

## Where Canopy differs

- Canopy is a hosted web drive with spaces and sharing, not a sync-first client.
- Edge-serverless deployment with platform-managed per-tenant blob storage; no sync client.
- A replacement for the retired portal's plugin model is still being decided.

## Pick Seafile if

You want a lean, fast, self-hosted Dropbox alternative with great sync.
