# TrueNAS

> A storage-first OS built on ZFS — the serious self-hosted storage substrate.

## What it is

A NAS operating system (TrueNAS SCALE) centered on **ZFS**: snapshots, replication, checksums, and
data integrity, plus shares (SMB / NFS / S3) and an apps system (containers) for services. Storage
and reliability come first; a polished consumer drive UI is not the point.

## Where it beats Canopy

- Best-in-class storage integrity: ZFS snapshots, replication, scrubs, RAID-Z.
- A true storage server you can build on; runs many services as apps.
- Mature and battle-tested for keeping bytes safe.

## Where Canopy differs

- Canopy is the **drive / portal layer**, not the storage stack — it can sit on top of TrueNAS (its
  filesystem or an S3-compatible share).
- Edge-native, plugin-extensible, with sharing and Document AI out of the box.

## Pick TrueNAS if

You want a rock-solid ZFS storage foundation and will layer file UIs and services on top.
