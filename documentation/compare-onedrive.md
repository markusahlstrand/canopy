# OneDrive

> Microsoft's drive — the natural choice inside Windows and Microsoft 365.

## What it is

A hosted drive integrated into Windows Explorer, Office, and the Microsoft 365 ecosystem, with
real-time co-authoring in Office, Files On-Demand, and good mobile apps. Business tiers add
SharePoint / Teams integration.

## Where it beats Canopy

- Deep Windows + Office integration; co-authoring in Word / Excel / PowerPoint.
- Files On-Demand and a mature sync client; strong enterprise identity (Entra ID).
- Zero ops, broad device support.

## Where Canopy differs

- Self-hosted, edge-native, storage you own; not tied to a Microsoft account or tenant.
- Extensible with sandboxed plugins; open source; OIDC for any identity provider.
- No Office co-authoring (collaborative **Markdown** is planned — not Word / Excel).

## Pick OneDrive if

You live in Windows + Microsoft 365 and want first-party integration and co-authoring.
